# Aqua Chat · 即时通讯平台

> 基于浏览器的全功能即时通讯客户端演示，纯前端实现，无服务端依赖。

---

## 快速开始

直接用浏览器打开 `chat.html`，或从桌面（`desktop.html`）点击 Dock 栏「聊天」图标进入。

**演示账号：**

| 用户名 | 密码 | 角色 |
|--------|------|------|
| `admin` | `admin123` | 管理员 |
| `alice` | `123456` | 普通用户 |
| `bob` | `123456` | 普通用户 |
| `carol` | `123456` | 普通用户 |

也支持「设备一键登录」和「长句密钥登录」。

---

## 本地服务器版（推荐 · 多设备实时聊天）

除了纯前端本地模式，你还可以 **在本地端口运行一个真正的聊天服务器**，实现多浏览器/设备间的实时消息、输入状态与管理员广播。

```bash
cd chat-server
npm install      # 仅需 express
npm run sync     # 同步前端到 public/（自动开启服务器模式）
npm start        # 启动服务 → http://localhost:3000
```

- **实时推送（SSE）**：消息/删除/编辑、输入状态、在线状态、管理员广播均秒推给在线客户端，无需刷新。
- **已读回执**：打开对话时立即标记已读，发送方气泡 `✓`→`✓✓` 双钻。
- **管理员广播**：管理员进入「后台 → 系统通知 → 发布广播」，全员实时弹窗。
- 数据存于 `data/aquachat.db`（SQLite，首次启动自动预置 4 个演示账号），删除 `data/` 重置。
- 验证：`npm test`（冒烟）、`npm run test:browser`（浏览器端到端实时）。

> 前端与纯前端版共享同一份 `js/chat.js`，检测到 `window.AQUA_CHAT_API` 后自动切换为服务器模式。

## 功能清单

### 一、用户认证（3 种方式）

| 方式 | 说明 |
|------|------|
| **设备登录** | 浏览器指纹自动识别，首次自动创建账号；首次登录弹安全须知并设置密码，设置后每次一键登录需校验密码 |
| **账号密码** | 注册 + 登录，带密码强度检测（6 级评分） |
| **长句密钥** | 中文/英文句子作为唯一凭证，同一句子映射同一账号 |

- 会话持久化（localStorage），刷新页面自动登录
- 登录/注册频率限制（5次/60秒）

### 二、即时消息核心

| 功能 | 说明 |
|------|------|
| **发送文本** | Enter 发送，Shift+Enter 换行 |
| **图片/文件** | 点击📎选择文件，图片内联显示，文件可下载 |
| **Emoji** | 😊 按钮打开 80+ emoji 面板，点击插入 |
| **贴纸** | 上传贴纸包，点击发送大号 emoji |
| **语音消息** | 🎤 模拟录音，显示时长 |
| **编辑消息** | ✏️ 修改已发送的文本（标记"已编辑"） |
| **撤回消息** | 🗑️ 软删除，显示"已撤回"占位 |
| **引用回复** | 💬 引用原消息，输入框上方显示引用块 |
| **转发消息** | ↗️ 选择目标聊天转发 |
| **收藏消息** | ⭐ 收藏重要消息，单独列表查看 |
| **表情反应** | 😊 切换爱心反应 |
| **@提及** | `@用户名` 蓝色高亮显示 |
| **已读回执** | 对方查看后显示 ✓✓ 已读标记 |
| **输入状态** | 实时显示"正在输入..." |

### 三、自毁消息（阅后即焚）

## 技术栈

| 层次 | 技术 |
|------|------|
| **前端** | HTML5 + CSS3 + Vanilla JavaScript (ES6, ~1900 行) |
| **存储** | IndexedDB（12 个对象仓库）+ localStorage |
| **图标** | Font Awesome 6.4.0 |
| **字体** | Inter + PingFang SC + Microsoft YaHei |
| **样式** | 纯功能性 CSS（~300 行），无 UI 框架 |

## 数据架构

### IndexedDB 对象仓库

| 仓库 | 主键 | 索引 | 说明 |
|------|------|------|------|
| `users` | id | username(唯一) | 用户基础信息 |
| `auth_creds` | id | userId, identifier | 多态凭证（device/password/key）|
| `devices` | id | — | 登录设备 |
| `messages` | id | chatId, time | 统一消息表 |
| `contacts` | id | owner | 联系人关系 |
| `groups` | id | name | 群组信息 |
| `channels` | id | — | 频道信息 |
| `channel_posts` | id | channelId | 频道帖子 |
| `sticker_packs` | id | — | 贴纸包 |
| `stickers` | id | — | 单张贴纸 |
| `secret_sessions` | id | — | 秘密聊天会话 |
| `admin_logs` | id | time | 管理操作日志 |

### localStorage 键

| 键前缀 | 用途 |
|--------|------|
| `aquaChat2_session` | 当前登录会话 |

| `aquaChat2_favorites` | 收藏消息 ID 列表 |
| `aquaChat2_selfDestruct` | 自毁倒计时秒数 |
| `aquaChat2_muted` | 静音聊天 ID 列表 |

| `aquaChat2_contactCats` | 联系人分组 |

### 安全
- 真实端到端加密（需要密钥交换服务器）
- 静态数据加密
- 设备登录安全提醒 + 密码校验（Server 版已实现，建议开启）

### 体验增强
- 国际化（i18n）多语言
- 消息线程 / 话题回复
- 定时/预约消息
- 位置共享

- 细粒度 RBAC 权限预设
- 真实数据分析图表
