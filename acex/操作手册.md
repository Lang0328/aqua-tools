## 1. 快速开始

### 1.1 打开方式

- 方式一：直接用浏览器打开 `chat.html` 文件
- 方式二：打开 `desktop.html`（桌面），点击桌面图标或 Dock 栏「聊天」入口
- 方式三：打开 `tools.html`（工具箱），在侧边栏「网络工具」中点击「Aqua Chat」

### 1.2 演示账号

| 用户名 | 密码 | 角色 |
|--------|------|------|
| `admin` | `admin123` | 管理员 |
| `alice` | `123456` | 普通用户 |
| `bob` | `123456` | 普通用户 |
| `carol` | `123456` | 普通用户 |

> 提示：可用不同浏览器（或浏览器无痕窗口）分别登录不同账号，体验互相聊天。

### 1.3 主题切换

页面使用 Aqua Tools 设计系统，支持 5 种主题：`aqua` / `midnight` / `aurora` / `aurora-light` / `liquid-glass`。主题在其它工具页切换后，聊天页自动跟随。聊天页侧边栏的 🌙 按钮可在深浅色之间一键切换。

## 2. 登录与账号

### 2.1 三种登录方式

登录页顶部有三个标签页：

**① 设备登录（默认）**
- 点击「设备一键登录」按钮
- 系统根据浏览器指纹自动创建/恢复账号，无需输入任何信息
- 设备 ID 显示在按钮下方，保存在浏览器本地

**② 账号密码**
- 已有账号：输入用户名 + 密码，点「登录」
- 新用户：在下方的注册框输入「注册用户名 / 密码 / 确认密码」，点「注册」
- 密码强度实时检测（6 级评分），输入弱密码会有提示
- 忘记密码：点击「忘记密码？」按提示重置

**③ 长句密钥**
- 在文本框输入一句只有自己知道的句子（中英文均可）
- 点「密钥登录/注册」：同一句子永远映射到同一账号，句子即凭证

### 2.2 账号安全功能

- **登录限流**：60 秒内最多尝试 5 次，超限会提示并暂停
- **会话保持**：登录后刷新页面自动保持登录状态
- **双因素验证（2FA）**：账号密码登录可开启模拟 2FA（详见第 12 节）

### 2.3 退出登录

点击侧边栏右上角的退出图标（↪），确认后退出当前账号。

## 4. 日常聊天

### 4.1 开始聊天

- 点击左侧任意联系人、群组或频道进入对话
- 首次使用可在「联系人」标签页点「+ 联系人」添加好友，或在搜索框搜索用户名直接聊天

### 4.2 发送消息

| 类型 | 操作方法 |
|------|----------|
| **文本** | 底部输入框输入，`Enter` 发送，`Shift+Enter` 换行 |
| **Emoji** | 输入框上方 😊 按钮，弹出分类面板（笑脸/手势/爱心/符号/动物）点击插入 |
| **图片 / 文件 / 视频** | 📎 按钮选择文件（支持 图片、视频、PDF、Office 文档），图片视频内联显示 |
| **贴纸** | 🧻 按钮选择贴纸包，点击发送大号表情；「贴纸」快捷键可上传新贴纸包 |
| **语音** | 🎤 点击开始模拟录音，再点结束，发送一条带时长的语音消息（点击气泡模拟播放） |
| **GIF** | 输入框上方 GIF 按钮，粘贴 GIF 图片 URL 发送 |
| **拖拽上传** | 直接把文件拖到消息区域即可发送 |
| **链接** | 粘贴 URL 自动识别并显示链接卡片，可点击跳转 |

### 4.3 特殊消息模式

**自毁消息（阅后即焚）**
1. 点击输入框上方的 💣 按钮开启自毁模式（按钮旁出现红色角标和「自毁 Ns」提示）
2. 正常发送消息，气泡上出现倒计时
3. 倒计时归零后消息自动变灰锁定，显示「消息已过期」
4. 再次点击 💣 关闭自毁模式

**@提及**
- 输入 `@用户名`，发送后用户名蓝色高亮
- 输入 `@all` 或 `@everyone` 可 @全体成员（红色高亮）

**投票**
- 在输入框输入 `#poll 问题|选项A|选项B|选项C` 格式，或使用群信息面板中的投票按钮
- 发送后成员可点击选项投票，实时显示百分比与投票人数

**Bot 命令**
在输入框直接输入以下命令，机器人会以系统消息回复：

| 命令 | 作用 |
|------|------|
| `/help` | 显示所有可用命令 |
| `/time` | 当前时间 |
| `/date` | 当前日期 |
| `/ping` | 延迟测试 |
| `/random` | 随机数字 |
| `/echo 内容` | 复述你输入的内容 |

### 4.4 消息气泡操作

将鼠标悬停在任意消息气泡上，顶部浮现操作按钮：

| 按钮 | 功能 |
|------|------|
| 💬 | 引用回复（输入框上方出现引用块，发送时附带原文） |
| ↗️ | 转发到其它聊天（可加转发备注） |
| 📋 | 复制消息文本到剪贴板 |
| ⭐ | 收藏消息（点输入区 ⭐ 按钮查看收藏列表） |
| 😊 | 打开表情反应面板（12 种 emoji），再次点击可取消自己的反应 |
| 🌐 | 翻译消息（模拟翻译） |
| 📌 | 置顶 / 取消置顶（置顶消息显示在聊天顶部横幅中） |
| ✏️ | 编辑消息（仅自己的消息，编辑后标记「已编辑」，点它可查看编辑历史） |
| 🗑️ | 删除 / 撤回（自己的消息可撤回；点按后选择删除范围） |

> 删除范围说明：**撤回** = 所有人不可见（显示「已撤回」占位）；**本地删除** = 仅自己隐藏。

## 5. 消息进阶操作

### 5.1 聊天内搜索

1. 打开聊天，点标题栏的 🔍 按钮
2. 输入关键字，实时显示匹配数量（如 `3/12`）
3. 用 ▲▼ 按钮在匹配结果间跳转，当前命中的消息黄色高亮
4. 点 ✕ 关闭搜索

### 5.2 消息筛选

点标题栏的 🧊 按钮，按「全部 / 文本 / 图片 / 文件 / 语音 / 贴纸」过滤当前聊天的消息。

### 5.3 多选批量操作

1. 点标题栏的 ☑️ 按钮进入多选模式
2. 依次点击要操作的消息（显示勾选）
3. 底部操作栏显示已选数量，可：
   - **转发**：把选中消息一起转发到其它聊天
   - **删除**：批量删除
   - **取消**：退出多选模式

### 5.4 消息详情辅助

- **已读回执**：对方查看后消息下方显示 ✓✓ 已读
- **正在输入**：对方输入时聊天区显示「正在输入...」
- **日期分隔线**：消息按日期自动分组（今天 / 具体日期）
- **滚动到底**：消息区右下角 ⬇️ 按钮一键跳转最新消息

## 6. 群组管理

### 6.1 创建群组

1. 点击侧边栏「+ 群组」按钮
2. 填写群名称、简介，选择类型：
   - **普通群组**：无人数限制
   - **超级群组**：有人数上限（默认 200，管理后台可调）
3. 创建成功后自动进入群聊

### 6.2 邀请成员与申请加群

- **邀请**：群内点标题栏「邀请」按钮，从用户列表勾选成员添加
- **邀请链接**：群信息面板中可生成 `aquachat://join/CODE` 形式的邀请链接，复制发给他人
- **申请加群**：非成员通过邀请链接或申请入口提交申请，群管理员在「群信息」面板中审批（批准/拒绝）

### 6.3 群信息面板

进入群聊后点标题栏「群信息」，右侧面板显示：
- 群公告（📢 管理员可发布）
- 成员列表及角色（创建者 👑 / 管理员 🛡 / 成员）
- 群主可操作：**转让群主**、**解散群组**
- 管理员可操作：设置成员角色、移除成员、删除群组
- 普通成员可操作：退出群组

### 6.4 群内互动

- 群投票（见 4.3）
- @全体（见 4.3）
- 群公告支持全员广播

## 7. 频道管理

### 7.1 创建与订阅

1. 点侧边栏「+ 频道」按钮，填写名称、简介
2. 选择「发布是否需要审核」（开启后帖子需管理员批准才公开）
3. 创建后自动订阅，出现在左侧列表

### 7.2 发布帖子

1. 进入频道，点标题栏「订阅/发布」按钮
2. 选择「发布帖子」，填写内容
3. 若频道开启审核，帖子状态为「待审核」，管理员批准后公开

### 7.3 频道管理（创建者 / 管理员）

- **点赞**：对帖子点 👍
- **编辑帖子**：作者或管理员可编辑已发布帖子
- **添加 / 移除管理员**：频道信息面板操作
- **查看订阅者**：频道信息面板查看所有订阅用户
- **删除频道**：创建者或管理员可删除整个频道

## 8. 秘密聊天（端到端加密）

用于与指定联系人建立加密会话：

1. 与联系人聊天时，点标题栏的 🔒「秘密聊天」按钮
2. 系统生成会话安全码（4 组十六进制，如 `A1B2:C3D4:E5F6:7890`）
3. 点「验证安全码」，确认「加密通道安全」后进入
4. 秘密聊天中的消息气泡带 🔒 锁图标

> 说明：本项目为纯前端演示，加密为模拟实现，实际端到端加密需后端密钥交换服务。

## 9. 联系人管理

### 9.1 添加联系人

- 点侧边栏「+ 联系人」，在弹出框搜索用户名 / 昵称，点「添加」

### 9.2 联系人分组

- 在联系人信息面板中创建 / 删除自定义分组
- 将联系人归入分组，侧边栏按分组展示

### 9.3 黑名单

- 在对方资料卡或联系人操作中点「屏蔽」，加入黑名单
- 被屏蔽后：对方无法向你发送消息（强制拦截）
- 在联系人设置中可取消屏蔽

### 9.4 用户资料卡

点击任意联系人头像，弹出资料卡，显示：头像、昵称、用户名、签名、在线状态、角色、最近在线时间、个人统计。提供快捷操作：
- 💬 直接聊天
- 🔒 秘密聊天
- 屏蔽 / 举报

### 9.5 举报

在资料卡中点「举报」，填写原因提交。管理员在管理后台「系统通知」中处理。

### 9.6 导入 / 导出联系人

- 在联系人设置中「导出」生成 JSON 文件备份
- 「导入」选择 JSON 文件批量恢复联系人

### 9.7 内容过滤

系统自动将敏感词替换为 `***` 后展示，营造安全的聊天环境。

## 10. 个人资料与设备管理

### 10.1 编辑个人资料

点击侧边栏头像或昵称，打开「个人资料」面板：

| 项目 | 操作 |
|------|------|
| 昵称 | 修改并实时保存 |
| 个性签名 | 一句话介绍自己 |
| 头像 | 点击头像上传本地图片（Base64 存储） |
| 修改密码 | 输入旧密码 → 新密码 → 确认 |
| 在线状态 | 双击角色文字循环切换：在线 / 离开 / 忙碌 / 隐身 |
| 个人统计 | 消息总数、群组数、注册天数 |

### 10.2 设备管理

点侧边栏 💻 按钮，查看当前账号的所有登录设备：设备名、指纹、最近活跃时间、可信状态。
- 移除不信任的设备记录
- 每个浏览器指纹对应一台设备

## 11. 管理后台（管理员专用）

管理员（如 `admin`）登录后，侧边栏出现 ⚙ 按钮，点击进入管理后台。

### 11.1 仪表盘

概览用户总数、群组数、频道数、消息总数、日活跃（模拟）。

### 11.2 用户管理

- 按用户名搜索
- 设为管理员 / 取消管理员
- 封禁 / 解禁（封禁用户无法登录发言）
- 删除用户

### 11.3 群组管理

搜索群组，解散任意群组（级联删除其全部消息）。

### 11.4 频道管理

搜索频道，删除任意频道。

### 11.5 消息审计

按内容搜索所有消息，查看状态：正常 / 已撤回 / 已过期。

### 11.6 流量统计

实时统计：今日发送消息数、今日注册数、当前在线数，附 7 日柱状图。

### 11.7 系统设置

| 设置项 | 说明 |
|--------|------|
| 消息保留天数 | 超过该天数的历史消息自动清理 |
| 最大群组成员数 | 超级群组人数上限 |
| 自毁消息默认时间 | 阅后即焚默认倒计时（秒） |

### 11.8 操作日志

记录管理员的关键操作（登录、创建群组、封禁、删除等），可追溯。

### 11.9 数据备份与恢复

- **导出备份**：将全部数据（用户/消息/群组/频道/贴纸等 12 个存储）导出为 JSON 文件
- **导入恢复**：选择备份文件覆盖恢复，完成后按提示刷新页面

### 11.10 系统通知

集中展示用户举报，可逐条标记「已处理」。

## 12. 个性化与偏好设置

### 12.1 深色模式

侧边栏 🌙 按钮切换深浅主题，选择自动保存。

### 12.2 聊天背景

进入任意聊天 → 信息面板 → 「设置背景」，粘贴图片 URL 或恢复默认背景。

### 12.3 免打扰 / 静音

信息面板中对单个聊天开启「免打扰」（🔔 静音），该聊天不再有提示音。

### 12.4 聊天归档

信息面板「归档」隐藏聊天但不删除数据；可在聊天列表底部「查看归档」恢复。

### 12.5 草稿自动保存

输入框内容自动保存为草稿，切换聊天后回来自动恢复。

### 12.6 导出聊天记录

信息面板「导出记录」将当前聊天导出为 JSON 文件。

### 12.7 双因素验证（2FA）

在个人资料或安全设置中开启模拟 2FA，登录时需额外输入验证码。

### 12.8 浏览器推送通知

允许浏览器通知权限后，收到新消息会弹系统通知（需页面处于打开状态）。

### 12.9 注销账号

在个人资料中选择「注销账号」，需两次确认，确认后清空本浏览器所有数据。

## 13. 数据管理与维护

### 13.1 数据存储位置

- **结构化数据**：IndexedDB 数据库 `AquaChatDBv2`（用户、消息、群组、频道、贴纸、日志等 12 个对象仓库）
- **配置偏好**：localStorage（主题、草稿、黑名单、置顶、归档等，键前缀 `aquaChat2_`）

### 13.2 数据备份

- 管理员：管理后台「数据备份」一键导出全部数据
- 普通用户：通过「导出聊天记录」保存单个聊天

### 13.3 数据恢复 / 清理

- 管理员：管理后台「数据恢复」导入备份文件
- 清空数据：浏览器开发者工具 → Application → 清除 IndexedDB / localStorage，或注销账号

### 13.4 常见异常处理

| 现象 | 处理 |
|------|------|
| 刷新后回到登录页 | 检查是否清除过 localStorage，重新登录即可 |
| 数据错乱 | 管理后台导出备份 → 手动清库 → 重新打开自动重建种子数据 → 导入备份 |
| 主题不生效 | 确认 `styles.css` 与 `chat.css` 在同一目录下正常加载 |
| 功能无响应 | 多为数据被改动，刷新或按上一条恢复 |

### 14.2 常见问题（FAQ）

**Q：为什么收不到对方的消息？**
A：本项目是纯前端模拟，两台设备之间**不会真实传输数据**。两个账号之间的互动（消息、已读、正在输入）在同一浏览器内通过模拟完成。想体验完整互动，请在同一个浏览器中用不同账号分别操作，或使用多开/分身功能开两个窗口（同一浏览器存储仍共享）。

**Q：消息保留天数会怎样生效？**
A：管理后台设置的天数用于自动清理，超过天数的历史消息会被删除。普通用户可随时导出记录做备份。

**Q：我能同时登录多个账号吗？**
A：可以。使用普通窗口 + 无痕窗口各登录一个账号即可并行体验。

**Q：数据安全吗？**
A：所有数据仅保存在本机浏览器，不上传任何服务器。清除浏览器数据即永久删除。
